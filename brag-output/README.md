# Brag launch video

Made with [/brag](https://github.com/latent-spaces/brag) and [Hyperframes](https://hyperframes.heygen.com/).

- `brag.mp4`: 24s, 1920x1080 render (the landing page tour is a web encode of this)
- `brag.jpg`: poster frame
- `brag-plan.md`, `composition-brief.md`, `share-copy.txt`: plan, brief, caption
- `composition/`: the Hyperframes project (`npx hyperframes render`)
- `build/`: template and script that generate `composition/index.html`
